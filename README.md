# 👻 Ghost Sort

Jogo de ordenação onde o jogador e o computador competem para ordenar fantasmas. O computador usa o **Insertion Sort**.

## Como jogar

1. Escolha a dificuldade (Fácil, Médio, Difícil).
2. Clique em **JOGAR**.
3. Use as setas:
   - **← →** movem o fantasma selecionado.
   - **↑ ↓** trocam a seleção.
4. Ordene todos os fantasmas antes do computador.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- **Insertion Sort**

## Como rodar

Abra o `index.html` no navegador. Pronto.
